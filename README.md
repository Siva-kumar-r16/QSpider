# 🎮 Java Game-Based Programs

Several larger Java programs were practiced to combine programming concepts into complete applications.

## ❌⭕ Tic-Tac-Toe

The Tic-Tac-Toe program combines:

- Java Swing
- Buttons
- Event handling
- 2D arrays
- Game state
- Player moves
- Win checking
- Draw checking
- Computer moves

The program also introduces basic game-AI concepts.

### Minimax

The Minimax algorithm is used to evaluate possible moves and select a move for the computer player.

The algorithm considers possible future game states and evaluates them to determine the computer's move.

### Alpha-Beta Pruning

Alpha-Beta pruning is used with Minimax to reduce unnecessary evaluation of game states.

It allows branches that cannot affect the final decision to be skipped.

# 🚫 Compiled Files

Compiled files should generally not be committed to the repository.

For Java projects, `.class` files are generated from `.java` source files.

Add the following to `.gitignore`:

```gitignore
*.class
```

This keeps generated Java bytecode out of the source repository.
