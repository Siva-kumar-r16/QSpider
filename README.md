## Suggested way to study

1. **Choose a topic** from the appropriate semester index.
2. **Read the topic notes first.** Semester 3 and Semester 5 are arranged by class day; Semester 4 is arranged by Java topic.
3. **Study the examples and syntax** in the notes, then open the related program files where provided.
4. **Try the program yourself** before looking at the existing solution. Change the input and trace how the output is produced.
5. **Revise regularly.** Revisit topics you find difficult and practice explaining the logic without reading the code.
