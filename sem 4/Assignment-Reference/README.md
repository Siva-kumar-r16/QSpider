# Assignment Reference

## Assignment examples in the Sem 4 scan (pages 40-42)

### Final score (page 40)

- Start with a score of `50`.
- Add a `40`-point win bonus.
- Subtract a `15`-point penalty.
- Add a `30`-point special reward.
- Subtract a `10`-point time penalty.
- The final score shown by the scan is `95`.

### Library books (page 41)

- Start with `120` books.
- Add `30` new books.
- Issue `25` books.
- Add `10` returned books.
- Remove `5` damaged books.
- The final number shown by the scan is `130`.

The scan uses these exercises to demonstrate assignment and compound assignment. The corresponding existing source files are [FinalScore.java](../Operators-and-Expressions/FinalScore.java) and [LibraryBooks.java](../Operators-and-Expressions/LibraryBooks.java). The compound assignment notes and worked bitwise expressions from page 42 are in [Operators and Expressions](../Operators-and-Expressions/README.md).
