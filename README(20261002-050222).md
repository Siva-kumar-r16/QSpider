# QSpider Placement Training – Sem 3 & Sem 4

This repository contains the programs, practice work, assignments, and notes completed during the QSpider placement training classes attended across **Semester 3 and Semester 4**.

The repository is organized date-wise so that the programs practiced in each class can be easily reviewed and revised.

---

Main areas covered:

- Slicing

- Conditional statements
- Functions
- Basic problem-solving programs
- `id()` and object identity

- Shallow copy
- Deep copy
- Classes and objects
- Class properties
- Instance members
- Class/static members
- Constructors
- `self`
- Instance methods
- Class methods
- Static methods
- `super()`
- Inheritance
- Single inheritance
- Multilevel inheritance
- Method overriding
- Polymorphism
- Operator overloading
- Duck typing
- Monkey patching
- Abstraction
- Encapsulation
- Public, protected, and private members
- Name mangling
- Banking-based OOP programs
- Basic algorithmic problem solving

## 🐍 Semester 3 – Python & OOP

Semester 3 focused mainly on Python programming, problem solving, and Object-Oriented Programming.

Some of the practice progressed from basic Python programs to complete OOP concepts such as inheritance, polymorphism, abstraction, and encapsulation.

The practice also included application-oriented programs such as banking systems and several programming problems involving strings, arrays/lists, matrices, brackets, numbers, and patterns.

---

## ☕ Semester 4 – Java

Semester 4 moved into Java programming.

The practice started with basic Java syntax and console programs and progressed into larger GUI-based applications.

Examples include:

- Number Guessing Game
- Rock Paper Scissors
- Connect Four
- Pong
- Tic-Tac-Toe

The Tic-Tac-Toe program also introduced algorithmic concepts such as **Minimax** and **Alpha-Beta pruning**.
