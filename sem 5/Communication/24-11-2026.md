## Exception for S + V + O

| Pattern | Rule / Description |
| :--- | :--- |
| **1. S + V** | No object needed |
| **2. S + V + C** | Linking Verbs |
| **3. S + V + O + O** | Two Objects |
| **4. Helping V + S + V** | Questions flip the order |
| **5. You + V + O** | Commands hide the Subject |
| **6. O + V + by S** | Passive form |

## Types of Sentence by Structure

1. **Simple:** IC
2. **Compound:** IC + and / but / or / so + IC
3. **Complex:** DC + IC
4. **Compound-Complex:** DC + IC + and + IC

---

## Sentences by Purpose

1. **Assertive:** Ends with `.`
2. **Interrogative:** Ends with `?`
3. **Imperative – order:** Ends with `.` & `!`
4. **Exclamatory:** Ends with `!`
