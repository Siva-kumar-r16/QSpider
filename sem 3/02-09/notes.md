**polymorphism** -> "one name, many,many forms".



it allows the **same function/method name** to behave differently depending on the object or how it's used.



in Python, polymorphism mainly shows up as:



1. method overriding(Run time polymorphism)
2. method overloading (compile time polymorphism- simulated in python)
3. operator overloading
4. duck typing
5. monkey patching (special flexibility in Python)





METHOD OVERRIDING (runtime polymorphism)

a child class provides a specific implementation







operator overloading



python allows classes to override operators (+,-,\*,etc) using magic methods like \_\_add\_\_,\_\_str\_\_.







abstraction

hiding internal implementation details and showing only essential features
